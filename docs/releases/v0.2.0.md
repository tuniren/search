Windows 10/11 x64 快捷启动工具。按 `Alt+Space` 呼出，支持中文、英文原名、拼音全拼和首字母搜索，按使用热度展示常用程序。

此版本新增 GitHub Releases 更新功能：在设置 → 关于中检查、下载并重启安装，支持下载取消、完整性校验、文件替换失败和新版启动失败时恢复旧版本。自动检查每天最多一次，下载和重启由用户触发。

提供两个完整解压包，均包含 Qt，无需安装 Python：

- **with-runtime.zip**：附带 VC++ 运行库，推荐下载，完整解压后运行 `search.exe`。
- **no-runtime.zip**：不附带 VC++ 运行库，需已安装 Microsoft Visual C++ v14 x64 运行库。

`update.json` 为程序读取的更新清单，手动安装不需要单独下载。请保留包内的 `package-info.json` 和 `installed-files.txt`。

0.1.0 尚无更新模块，首次升级请将完整包解压到新目录。设置、固定项和使用热度会保留；旧版 KeySeek 数据目录会继续沿用。开启过开机启动时，启动新版会刷新对应路径。
