Windows 10/11 x64 快捷启动工具。按 `Alt+Space` 呼出，支持中文、英文原名、拼音全拼和首字母搜索，按使用热度展示常用程序。

新增系统入口搜索：控制面板、Windows 设置、网络、Wi-Fi、代理、VPN、显示、声音、设备管理器等。支持中文、英文和拼音搜索，显示原生图标，沿用固定、自定义别名和使用热度。

**同版本修复包**：修复干净构建中 Qt DLL 被放入 `bin`，导致其他电脑提示找不到 `Qt6Sql.dll` / `Qt6Widgets.dll` 等文件的问题。现在 DLL 与 `search.exe` 位于同一目录，并对 ZIP 执行隔离 Qt 环境的启动检查。遇到该问题请重新下载本页附件，完整解压到新目录后运行，版本号仍为 0.2.0。

此版本新增 GitHub Releases 更新功能：在设置 → 关于中检查、下载并重启安装，支持下载取消、完整性校验、文件替换失败和新版启动失败时恢复旧版本。自动检查每天最多一次，下载和重启由用户触发。
