# search 设计

## 范围

仅支持 Windows 10/11，搜索开始菜单程序、Windows 设置、控制面板及常用系统工具。包含可由全局快捷键呼出的搜索面板、独立设置窗口及托盘菜单。界面用命令式 C++ 编写，不使用 Designer、XML UI 或 QML。

当前用户与所有用户的开始菜单都纳入发现范围，补充 AppsFolder 中注册的商店应用和内置系统入口。普通文件、目录、文档快捷方式及未加入开始菜单的第三方独立 EXE 不参与搜索。网页搜索、算式解析和全盘扫描不属于当前产品范围。

## 工具与组件

- C++20、Qt 6 Widgets；使用 QListView、QAbstractListModel 和 delegate 呈现结果。
- CMake Presets + Ninja；vcpkg manifest 固定 baseline。支持本机 MSVC x64 Qt SDK。
- Qt Concurrent 负责后台任务，SQLite 保存程序快照及个性化记录。
- Windows Known Folders、Shell COM、RegisterHotKey 和 ReadDirectoryChangesW 提供系统集成。

Qt 父子所有权管理界面对象，RAII 管理线程、数据库连接及 COM 资源。模块之间采用普通 Qt 信号与槽，不另建 UI 框架。

## 程序发现

通过 FOLDERID_Programs / FOLDERID_CommonPrograms 获取实际开始菜单位置，递归枚举 `.lnk` 和 `.appref-ms`。解析 Shell Link 的目标，仅收录可启动的程序、脚本及管理控制台；指向文档和目录的快捷方式跳过。运行时仍打开原始快捷方式，保留工作目录、参数及 Shell 启动行为。

AppsFolder 补充带包身份的应用。快捷方式以规范化路径标识，商店应用以 AUMID 标识；相同路径去重，不按显示名称合并不同程序。

`platform/system_entries` 集中声明常用 Windows 10/11 系统入口、类型和中英文关键词。设置使用官方 `ms-settings:` URI，控制面板使用 Shell GUID，管理工具使用 Windows System32 中实际存在的系统文件；通过 ShellExecute 打开，不将查询内容拼接为命令。系统入口不依赖开始菜单，进入同一快照、搜索与使用记录流程。设置根入口沿用原 AppsFolder 的身份，保留已有热度、固定和别名，同时跳过重复的 AppsFolder 设置项。

开始菜单变动合并两秒后刷新，每十分钟重新枚举；托盘和设置也提供手动刷新。索引任务使用独立的单线程工作池。刷新完成后发布不可变共享快照，搜索任务持有旧快照直到结束。

## 名称与拼音

搜索支持 Unicode 规范化、不区分大小写的原名匹配、前缀、包含与短名称的子序列匹配。第三方程序不按 EXE 路径匹配，不自动添加翻译名；用户可自行设置别名。

中文名称预先转换成逐字读音序列，包含全拼和首字母匹配所需的数据。字表来自固定版本的 MIT pinyin-data，随二进制离线使用。多音字保留所有读音；匹配过程传播查询位置，避免枚举多音字组合。支持全拼前缀、音节边界内的后缀查询及首字母；不提供词义消歧。

常见 Windows 系统程序由实际 Windows 目录目标或明确的 Microsoft 包身份识别，增加中英文名称，例如记事本 / Notepad、计算器 / Calculator。不能仅根据快捷方式显示名称判断系统程序。别名也建立拼音键。映射不创建新的启动入口，未出现在发现结果中的程序不会凭别名被添加。

名称精确匹配优于前缀及拼音匹配，固定项、启动次数和最近使用记录提供小幅加权。结果最多显示四十项。

空查询只显示已使用或固定的程序，固定项优先，其余按累计启动次数降序排列，相同次数按最近使用时间排序，最后按名称稳定排序。每次 Shell 成功接受打开请求后，启动次数加一并更新最近使用时间；打开所在位置、复制路径或启动失败不计入热度。记录写入 SQLite，同时发布新快照更新列表；成功打开后清空搜索词，下一次唤起直接显示常用程序。清除使用历史会将次数及时间归零，保留固定项和别名。

## 查询与界面

输入防抖二十五毫秒。查询工作池最多同时执行一个任务，新输入取消旧查询并覆盖待执行请求。任务携带代次，只有代次、输入内容及输入法状态都吻合时才能更新结果。

中文输入法组词期间不接管候选词按键，也不执行结果。模型刷新前复制所选 ID，刷新后尽可能恢复选择。执行前复制结果对象，避免信号回调刷新模型后产生悬空引用。

透明窗口的阴影由顶层窗口独立绘制，不在输入框及列表的父组件上使用 graphics effect，避免滚动、输入法编辑和尺寸变化时缓存旧画面。结果数量改变时先更新内层布局，再调整窗口高度。

程序图标通过 Windows Shell 的 IShellItemImageFactory 获取，失败时回退到 SHGetFileInfo；保留快捷方式的自定义图标并支持商店应用。独立单线程池只读取 QImage，GUI 线程创建 QPixmap / QIcon。模型以目标路径缓存最多 256 个图标，按 DecorationRole 更新对应行；查询改变时替换待加载队列，过期请求不会更新其他程序的图标。加载中及读取失败时使用默认程序图标。

全局快捷键使用 Qt 原生事件过滤器。线程消息的 native result 指针可能为空，必须判断后写入。搜索、索引和 Shell 动作各自使用有界工作池；退出时取消并等待工作线程，界面只在主线程修改。

## 设置与存储

设置包含全局快捷键、主题、失焦收起、登录启动及自动检查更新。搜索页显示程序来源、手动刷新和历史清理；关于页提供仓库链接、版本检查、发布说明和更新下载。移除文件目录、排除名称及网页搜索设置。

SQLite `items` 保存 id、name、target；`usage` 独立保存启动次数、最近使用、固定状态和个人别名。后台枚举替换快照，保留个性化记录。结果类型、拼音和内置别名属于派生数据，在读取缓存后重新生成，不改变数据库版本。设置和控制面板展示友好类别，不展示原始 URI；虚拟入口不提供“打开所在位置”。设置使用 Windows 设置图标，控制面板通过 Shell 获取图标，失败时回退到控制面板程序图标。

数据库版本 2 从版本 1 原子迁移：移除文件及目录条目和对应记录，删除旧 kind 字段，保留程序历史、固定项和别名。设置读取忽略旧文件索引字段，保存时移除废弃配置。

## 验证

核心测试覆盖中文、英文、全拼、首字母、多音字、第三方不自动翻译、排序、取消和旧数据库迁移。桌面测试使用临时开始菜单目录和真实 Shell Link，验证递归发现、去重、过滤文档与目录、系统别名、输入法和快速输入切换；不修改用户开始菜单。

Release 构建保留调试符号用于崩溃定位，PDB 不进入发布包。部署使用 Qt 官方部署工具和 CMake 的 MSVC 运行库发现，输出 `dist/search.exe`、独立更新程序、Qt DLL、应用本地 CRT DLL 及 Windows / SQLite / ICO / Schannel 插件。以 CRT DLL 替代完整运行库安装程序；跳过未使用的图像、网络、数据库、TUIO 及样式插件。Qt Network 用于本机单实例 IPC 和 HTTPS 更新请求。

部署先安装到全新的暂存目录，成功后替换 `dist`，旧目录保留在构建目录中；不向旧目录累积文件。Python 打包脚本独立从安装规则生成发布包，避免打入开发工具或遗留文件。Python 3.10+ 用于打包和原生更新程序的集成测试，仅使用标准库。

安装规则分成 Application 和 Runtime 两个组件，`scripts/package.py` 将它们组合成唯一的 `with-runtime` 包，包含 Qt DLL、插件和 VC++ 运行库。`build.ps1 -Package` 调用同一 Python 脚本，生成一个 ZIP 和更新清单；`dist` 默认安装全部组件。脚本使用独立临时目录暂存文件，校验 ZIP 后原子替换输出文件，并移除同版本的旧 `no-runtime` ZIP。

桌面测试还覆盖自定义快捷方式图标、加载期间替换结果，以及列表滚动、输入法提交和过滤后的实际屏幕像素与完整重绘结果对比。

更新状态与搜索流程独立，网络请求使用 Qt 异步 API。更新程序使用静态 CRT 和 miniz，不依赖待替换的 Qt DLL。文件清单、持久化事务日志、备份和启动确认共同管理安装与恢复，详见 [更新与发布](updates.md)。

后续可补充匹配高亮及更多系统组件别名。混合 DPI、无障碍和干净 Windows 虚拟机兼容性仍需进一步验收。
